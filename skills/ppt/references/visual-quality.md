# 视觉工艺检查

这些是诊断问题与默认 token，不是版式配额。用户品牌、选定方向和题目语义可以推翻默认值，但不能推翻可读性、层级和不重叠。

## 构图与注意力

- 观众第一眼会看哪里，第二眼会看哪里；如果所有元素同权重，重新建立层级
- 独立文字或单一结构块若靠左放置，检查右侧是否有视觉重量、刻意张力或明确留白理由；没有时考虑居中
- 非对称、full-bleed、split、网格、卡片、舞台式居中都可以使用，前提是服务当前内容
- 卡片适合真正并列、独立、需要扫描的对象；流程、关系、前后变化和空间结构不要默认拆成等大卡片
- 相邻页面可以重复语法形成章节稳定，也可以换语法制造转折；用 contact sheet 判断重复是节奏还是惰性
- 题目专属视觉可以是真实媒体、数据图、架构、场景、文字编排或新组件，不把“有图标”误当成已经可视化

## 间距与可读性

- 使用主题的 `--space-*` token 建立标题、内容块、卡片内边距和图表标注间距；不同主题可以调整数值
- 带边框、阴影或底色的同级块不能视觉粘连；图形标注不能压住柱、线、节点或人物
- 不用拉伸高度掩盖内容不足，也不用缩小字号解决结构问题
- 字号取决于放映距离、语言、信息类型和密度。普通正文优先保持远距离可读；表格、代码和引用可更小，但必须实际截图检查
- 最长标题、最长标签、最大数字和最密页面都要单独抽查

## 字体、颜色与素材

- 字体角色由本次设计声明和主题 token 决定，不强制标题衬线或正文无衬线
- 颜色先承担层级和语义，再承担装饰；具体状态色含义由当前业务决定
- 同一套照片、截图、插画和生成图保持视角、材质、光线、线条或裁切逻辑一致
- 真实素材不要被过度模糊、裁切或装饰到无法识别；截图框和卡片框不是所有媒体的默认容器
- 纸纹、玻璃、阴影、渐变、手绘和 3D 都是材料选择，不是“高级感”快捷键

## 数字、图表与动效

- 需要按步揭示、比较或强调的主数字优先使用 `BigNumber`、`Num`、`Compare` 或 NumberFlow 图表
- 表格单元格、坐标轴、日期、版本、ID 和同时出现的大量数字保持静态，并使用 tabular numerals
- 图表标注跟随数据对象；刻度、比例和视觉面积不能制造错误印象
- 动效解释出现、变化、因果、空间关系或连续身份；一页有一个清楚的运动主意通常已经足够
- 逐步前进和回退都要成立；`prefers-reduced-motion` 与 print 模式必须给出稳定、清楚的状态

## 验收

1. 在 1280×720 预览中检查首帧、每一步、回退和最终帧
2. 用浏览器确认控制台、资源、文字、图片、图表和共享元素状态
3. 导出草稿 PNG 并打开 `contact-sheet.html`，检查整套节奏与素材一致性
4. 按 [evaluation.md](evaluation.md) 区分浏览器事实、截图判断、阻断项和回流目标
5. 出现问题时优先改结构、层级和素材，不先缩字或叠装饰
