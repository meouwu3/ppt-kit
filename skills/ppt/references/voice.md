# 中文 PPT 文案：去 AI 味

“像人写的”不是故意口语化，也不是加入情绪、玩笑或第一人称。公司 PPT 的自然感来自真实材料、明确说话人和可核对的细节。

## 语气来源

按以下顺序确定语气：

1. 用户提供的原文、旧 PPT、讲稿和聊天用语
2. 用户所在团队已经使用的术语和表达
3. 没有语料时，使用简洁、克制的内部汇报语气

用户提供了足够语料时，摘取有代表性的句子，记录句子长度、常用动词、术语、第一人称习惯和标点。保留用户有辨识度的说法，不把口语统一升级成抽象书面语。

## 常见 AI 痕迹

- **拔高意义**：把普通事实写成“标志着”“彰显了”“开启新篇章”“反映更广泛趋势”
- **宣传语气**：没有证据就写“领先”“卓越”“强大”“全面”“深度”“创新”“赋能”
- **虚构误解**：自动使用“不是 A，而是 B”“不只是 A，更是 B”，好像观众先有错误认识
- **强凑三项**：为了完整感写三个形容词、三个价值或三个平行短语
- **模糊权威**：使用“行业普遍认为”“研究表明”“用户反馈显示”，却没有具体来源
- **空转连接**：使用“值得注意的是”“可以看出”“由此可见”“总而言之”，后面没有新事实
- **名词堆叠**：写“进行流程的优化”“实现能力的提升”，不说谁做了什么
- **重复结论**：标题、图表、正文和页底用不同说法重复同一件事
- **公式化结构**：每页都用相同句式、三段式、冒号标题或整齐得过头的列表
- **聊天残留**：把“当然”“希望对你有帮助”“接下来让我们看看”等助手话术放进页面

这些是修改信号，不是机械禁词。原文引用、必要对比和有证据的结论可以保留。

## 改写方法

- 优先写“谁做了什么，结果怎样”
- 用具体名词、动作、时间、数字和对象替代抽象评价
- 一句话没有新增事实、判断或行动时，直接删除
- 两项就够时不要补成三项；事实有四项时也不要硬删成三项
- 重复术语比刻意换同义词更自然
- 页面允许短语和短句；完整推导放 notes，不在可见文案里解释给模型自己听
- 不新增原文没有的观点、情绪、人物口吻或确定性

## 示例

| AI 味写法 | 改写 |
| --- | --- |
| 这不仅是一次升级，更是体验的全面重塑 | 新版把提交步骤从 5 步减到 3 步 |
| 以创新驱动增长，开启发展新篇章 | 下季度先在华东区试点 |
| 坚持长期主义，持续创造价值 | 没有新增事实或行动，删除 |
| 通过多维协同全面赋能发布流程 | 把发布检查接入 CI |
| 实现了处理效率的显著提升 | 写成材料中的原值、现值和具体改动；没有数据就不写“显著” |
| 行业普遍认为该方案具有重要价值 | `<Todo owner="来源提供人">`：补具体来源或删除 |

## 审校流程

完成首稿后，对标题、可见文案和 notes 做一次 `draft -> audit -> final`：

1. 标出无法对应用户原文、数据、截图或明确推理的句子
2. 标出拔高、宣传、否定式排比、强凑三项、模糊归因和填充连接
3. 只重写问题片段，保留事实、术语、数字、限定条件和原有语气
4. 再读一遍，确认每句话都比修改前更具体，没有为了“人味”新增个性
5. 朗读可见文案；讲述者现场不会这样说的句子继续删改

逐句问：

- 这句话新增了什么
- 讲述者能指出它的来源吗
- 换到任何公司的 PPT 里是否仍然成立；若是标准议程、合规声明或刻意普适的主题观点，再判断它是否服务当前任务
- 能否改成明确主体和动作
- 删掉后是否损失事实、逻辑或必要语气

第三个问题回答“是”，通常说明文字太泛。

## 可复用提示词

```text
对下面的 PPT 文案做一次去 AI 味审校

保留事实、数字、专有名词、用户原话和必要限定，不新增观点或数据
只改有问题的片段，不把整套文案统一成另一种模板语气

重点检查：
- 夸大意义和宣传词
- “不是 A，而是 B”“不只是 A，更是 B”
- 强行三段式、对仗和金句
- 模糊归因、空泛连接和重复结论
- 名词堆叠、被动句和没有主体的动作
- 任何可以放进其他公司 PPT 的通用句子

优先改成：谁做了什么，结果怎样
输出最终文案，并单独列出仍缺来源、不能确认的句子
```
