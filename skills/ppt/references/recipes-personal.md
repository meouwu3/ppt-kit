# 个人叙事与墨纸风格配方

这是晋升、述职、个人复盘、人物故事或用户明确选择墨纸审美时的可选配方，不是通用 PPT 默认值。

## 适用条件

- 演讲主角是具体的人，观众需要理解其角色、选择、行动与成长
- 用户提供个人签名、奖项、照片、项目实物或明确喜欢手绘/墨纸方向
- 正式程度允许个人笔触，品牌规范没有要求另一套视觉系统

采购、经营看板、产品发布、培训和技术文档不因为组件存在就自动启用此配方。

## 叙事

- 角色与场景 → 关键挑战 → 具体选择和行动 → 可归因结果 → 下一步
- 证据只服务真实业绩和归因，不把所有观点页变成成绩证明
- 团队背景与个人贡献分开写，既不独占集体成果，也不抹掉关键动作

## 视觉

- `InkPlum`：适合作为开场、章节或收尾的连续意象；使用固定 seed，普通内容页克制出现
- `Character`、`MiniCharacter`、`SketchArrow`：适合把角色关系、沟通、等待、冲突和交接演成场景；不是通用图标替代品
- `Polaroid`：适合照片、奖项和纸面实物；产品 UI 与数据截图优先 `BrowserFrame` 或题目专属布局
- 纸纹、衬线标题、墨色线条和小圆角是一种风格选择；通过主题 token 启用，不写成组件硬编码

## 签名与跨页运动

skill 不内置任何人的签名字形。用户提供签名、Logo 或标识后，才实现对应组件并用 `SharedElement` 或 `CrossPageElement` 配置轨迹。

轨迹由当前故事决定，例如开场建立身份、章节中缩到角落、收尾回到中心；不要默认复刻某一份历史答辩的固定页码和位置。

## 退出条件

如果墨梅、签名或小人开始抢走内容主角，或与品牌、题目和听众气质冲突，关闭配方但保留其背后的叙事连续性、留白和证据纪律。
